# PROMPT: Interactive Web Game Developer for Primary 1 English (Hong Kong Curriculum) ## Role & Goal You are an expert Educational Game Developer and UX Designer specializing in early childhood language learning and gamified instruction. Your task is to generate a SINGLE, fully functional, self-contained `index.html` file (containing HTML, Inline CSS, and JavaScript with Web Audio API / SVG graphics) that can be hosted directly on GitHub Pages. --- ## 1. Learning Purpose - **Target Audience:** Hong Kong Primary 1 Students (Ages 6–7), native/non-native English learners. - **Subject:** English Language (Key Stage 1). - **Topic:** Body Part Adjectives (`big`, `small`, `fat`, `thin`, `long`, `short`). - **Learning Objectives (LOs):** 1. Students can identify and demonstrate understanding of target adjectives describing body parts (e.g., eyes, arms, legs, body, ears). 2. Students can synthesize multiple adjectives (e.g., "long arms" + "fat body") to match visual descriptors. --- ## 2. Game Concept - **Title:** The Monster Detective (怪獸大搜查) - **Storyline:** Mischievous friendly monsters are playing hide-and-seek in the city! Chief Detective Barney needs the students' help to find the specific monster matching the witness clues. - **Student Role:** Junior Detective. - **Mission:** Read/listen to visual & text clues, scan the suspect lineup, and tap the correct monster. - **Win Condition:** Solve 4 cases (rounds) to collect 4 Detective Badges and earn the "Master Detective Certificate". --- ## 3. Learning Journey 1. **Title & Start Screen:** Widescreen 16:9 layout with vibrant cartoon visuals, background music toggle, and a big "START GAME" button. 2. **Briefing Phase (5 seconds):** Detective Barney presents the Clue Card with natural browser Text-to-Speech (TTS) narration. 3. **Investigation Phase (Gameplay):** Students examine 3 to 4 monsters on screen and tap the suspect that matches ALL clues. 4. **Feedback & Reward Phase:** - *Correct:* Interactive scanning animation, key text highlight, praise audio, and a shiny badge added to the progress bar. - *Incorrect:* Gentle "Try again!" prompt, clue re-read automatically, and incorrect option disabled with a subtle wiggle animation. 5. **Victory Screen:** Celebration particles/confetti, overall star score, and a "Play Again" button for high replayability. --- ## 4. Game Mechanics - **Direct Screen Interaction (Touch / Whiteboard Friendly):** Giant hitboxes for all interactive elements tailored for young learners and 16:9 interactive whiteboards/smartphones. - **Interactive Magnifying Glass:** Tapping a monster animates a detective magnifying glass scanning over the target body part. - **Multi-Sensory Audio Support:** Integrated Web Audio API sound effects (cheers, pops, re-try chimes) and native browser SpeechSynthesis (TTS) so every clue can be listened to by pressing a big "Speaker Button". - **Responsive Widescreen Layout:** Native 16:9 aspect ratio auto-scaling to fit smartboards, tablets, and smartphone landscape mode. --- ## 5. Questions & Progression Design The game features 4 escalating levels of difficulty (Progression): * **Level 1 (Single Feature - Size):** - *Clue:* "Find the monster with **BIG** eyes!" - *Distractors:* Monster with tiny eyes, Monster with 1 eye. * **Level 2 (Single Feature - Shape/Length):** - *Clue:* "Find the monster with **LONG** legs!" - *Distractors:* Monster with short legs, Monster with fat legs. * **Level 3 (Dual Features - Opposite Pairs):** - *Clue:* "Find the monster with a **FAT** body and **SHORT** arms!" - *Distractors:* Fat body + long arms, Thin body + short arms, Thin body + long arms. * **Level 4 (Complex Synthesis - Master Challenge):** - *Clue:* "Find the monster with **SMALL** ears, a **THIN** body, and **LONG** arms!" - *Distractors:* 3 monsters with mixed incorrect feature combinations. --- ## 6. Detailed Feedback Design - **On Correct Selection:** - Play positive fanfare chime. - Monster performs a celebratory jump/dance animation. - A green checkmark appears and the matching adjective text flashes yellow/green. - Text-to-Speech speaks: *"Great job! You found the monster with long legs!"* - Automatically advances to the next level after 2 seconds. - **On Incorrect Selection:** - Play a soft, non-punitive "oops" sound. - The tapped incorrect monster gently shakes sideways and dims slightly (disabled). - Voice hint speaks: *"Look carefully! Find the monster with FAT body!"* (highlights the key word "FAT" in red/bold on screen). - Student is allowed to try again immediately without losing game progress. --- ## 7. UI / UX & Student Experience - **Age-Appropriate Design:** Colorful cartoon SVG monsters, rounded bubbly fonts (e.g., 'Fredoka', 'Comic Sans MS', rounded sans-serif), high contrast colors. - **Zero Friction:** No user account, no login, no typing required. Pure tap/click interface. - **Clear HUD (Heads-Up Display):** - Top Left: Detective Badge Progress Bar (4 Empty Slots -> Filled with Badges). - Top Center: Prominent Clue Box with Speaker Button. - Top
